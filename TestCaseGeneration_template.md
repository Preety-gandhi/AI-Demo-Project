Test Cases from Acceptance Criteria

Spec: @file specs/[spec-id].md

For each acceptance criterion in the Acceptance Criteria section:

1. Convert the AC into one or more test cases (happy path + edge/failure cases).
2. Name each test with the AC ID it traces to (e.g., test_AC1_skeleton_renders_within_100ms).
3. Write test cases according to the  Given/When/Then format --- do not implement test code yet.
4. List any mocks or fixtures needed for each test.
5. Verify each test is binary (pass/fail) and can run independently.

Do not write implementation code. Produce test cases only.
